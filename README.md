## Книга

> *«И только тьма и тишина…»*

Разочарованная своей жизнью, Мари погибает и попадает в Корпорацию «Универсалис» – метафизическое чистилище, устроенное как бесконечная бюрократизированная организация со строгой вертикалью власти и четкими процессами распределения душ между «Адом» и «Раем». Некогда пониженный в должности Харон предлагает ей сделку – «помоги мне стать здесь главным, и я гарантирую твоей семье распределение в рай». Но в борьбе за власть все обещания имеют двойное дно.

**«Искупление»** — роман в работе. О вине, искуплении, абсолютной власти и бумажной волоките между ними.

## Архив

В этом репозитории — спутник книги: веб-приложение, которое выглядит и ведёт себя как справочный терминал Корпорации Универсалис. Янтарный фосфор, выпуклый кинескоп, строки развёртки, загрузочная последовательность — и время от времени сообщения на пейджер прямо из Чистилища.

| | Раздел | Что внутри |
|:-:|---|---|
| 📼 | **Хроника** | Поглавная хронология событий и лор, который открывает каждая глава |
| 🗂️ | **Личные дела** | Досье персонажей, предыстории, связи и концепт-арты, из которых они выросли |
| 🗃️ | **Картотека** | Глоссарий отделов, должностей, документов, мест и законов загробного мира |

**Защита от спойлеров.** При первом визите терминал запрашивает *уровень допуска* — последнюю прочитанную главу. Всё, что дальше, скрыто чёрными плашками со штампом **СЕКРЕТНО**. Рассекретить можно — если хватит смелости.

**Два языка.** Русский и английский, переключаются в любой момент.

**Цветные арты на монохромном экране.** Интерфейс светится одним цветом фосфора, а дизайны персонажей и мудборды «проявляются» в полном цвете — как фотографии, подколотые к делу.

## Для любопытных

Приложение лежит в папке [`app/`](app). Весь лор хранится обычными файлами Markdown и YAML в [`app/content/`](app/content), так что архив растёт вместе с книгой без правок кода.

```bash
cd app
npm install
npm run dev
```

Техническое руководство — редактирование контента, разметка, темы и работа с изображениями: [`app/README.md`](app/README.md).
